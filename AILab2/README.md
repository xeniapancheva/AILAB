# Лабораторная работа №2: Игра против ИИ (Алгоритм Minimax)

## 1. Описание выбранной игры
Выбрана классическая игра **«Крестики-нолики 3×3»**. 
Два игрока по очереди ставят знаки («X» и «O») на поле 3×3. Цель — первым выстроить ряд из трех своих символов по вертикали, горизонтали или диагонали. Реализован режим игры «Человек против ИИ».

## 2. Как работает Minimax
Алгоритм **Minimax** — это рекурсивный алгоритм принятия решений для игр с полной информацией и нулевой суммой:
* ИИ строит полный граф (дерево) возможных ходов до терминальных состояний (победа, поражение, ничья).
* На уровне хода **ИИ (Max)** выбирает ход с максимальной оценкой.
* На уровне хода **соперника (Min)** алгоритм рассчитывает на наихудший сценарий и выбирает минимальную оценку, предполагая, что человек играет оптимально.

## 3. Описание оценочной функции
Оценочная функция анализирует финальное состояние игровой доски и возвращает числовое значение:
* **Победа ИИ**: $+10$ баллов
* **Победа человека**: $-10$ баллов
* **Ничья**: $0$ баллов

## 4. Пример хода ИИ и объяснение
* **Ситуация**: Человек делает первый ход и ставит крестик в центр (ячейка `4`).
* **Выбор ИИ**: Алгоритм просчитывает все 8 оставшихся вариантов и делает ход в один из углов (например, ячейка `0`).
* **Причина выбора**: Угловые ячейки обладают высокой стратегической ценностью, так как участвуют в 3 возможных выигрышных линиях (в отличие от боковых ячеек), блокируют развилки игрока и создают максимальное количество сценариев для построения выигрышной комбинации ИИ.

## 5. Ограничение глубины поиска и причина его использования
* Для игры «Крестики-нолики 3×3» размер полного дерева решений крайне мал (максимум $9! = 362\,880$ состояний, а с учетом симметрии и завершения партий — существенно меньше).
* По этой причине **ограничение глубины поиска не используется**: современный процессор выполняет полный перебор мгновенно, гарантируя идеальные (непобедимые) ходы ИИ на протяжении всей партии.
